# FIN-P3-INFO-GAIN-03B：F 轨组合相对成员比较

02C 已证明 F 轨成员输入未冻结；COMBOS 也没有 F 轨组合预测结果。03B 因此产生 55 条正式 `not_evaluable` 比较（3 个组合、11 个成员、5 项指标），不填零、不创建预测输入、不调用 F 评价器。

每条记录的原因均为 `F_COMBO_AND_MEMBER_CONTEXT_NOT_FROZEN`。这不是 F 轨表现为零，也不是信息增益为零；它只保留当前证据不可比较的事实。要实施实际 F 比较，必须另行冻结组合和成员的 PIT 预测标签、相同基准、相同训练/校准/测试切分与区间定义。

本任务不选择成员、不做综合信息增益判断、不改写 F 的 `not_run` 状态，也不产生准入、生产、收益或交易结论。
